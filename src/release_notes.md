## What's Changed

### Microsoft.Azure.Functions.Extensions.Connector

- Add preview support for Connector Namespace Poll triggers with single-event
  and batched delivery, configurable concurrency, Poll message IDs, and
  scaling based on pending events.

### Microsoft.Azure.Functions.Worker.Extensions.Connector

- Add preview support for Connector Namespace Poll triggers in .NET isolated
  worker apps, with single-event and batched delivery and Poll message IDs.
